# Add ADR-20260131001 compliance lint for justfile/devbox.json patterns


Add a lint step to validate compliance with ADR-20260131001 Standard Developer UX Flow.

The lint should check:

1. **Primary Flow Compliance**: Ensure projects follow 'direnv → devbox → just (*-internal)' pattern
   - External recipes call 'devbox run <command>' (not 'devbox shell <command>')
   - Internal recipes (*-internal suffix) contain actual implementation
   - devbox.json scripts point to *-internal targets

2. **Required Targets**: Verify all required ADR targets exist:
   - bootstrap, bootstrap-internal
   - prime, prime-internal  
   - doctor, doctor-internal
   - clean, clean-internal
   - build, build-internal
   - lint, lint-internal
   - test, test-internal

3. **Script Pattern Validation**:
   - devbox.json init_hook calls bootstrap-internal
   - All devbox.json scripts point to just *-internal targets
   - No direct command calls in devbox.json scripts

4. **File Structure Compliance**:
   - justfile exists with proper target structure
   - devbox.json exists with required packages and scripts
   - .envrc exists with proper devbox integration

5. **Package Requirements**:
   - 'just' package included in devbox.json
   - Language-specific packages as defined in ADR table

This prevents ADR drift and ensures consistent developer experience across all projects.
